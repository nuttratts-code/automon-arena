# Set 93 review — why HL-7 deals 20k–88k damage in one match (cause only, nothing changed)

Source: Balance Room results/latest (5 Nov 09:07Z, n 24000 seed 4242 — same values as code after set 92). Replayed with `node lab/replay.mjs <lv> <i>` + a scratch trace of HL-7's armor/atk gains.

## Cause (evidence)
HL-7 kit: `hitTaken → atkOf { armor, self } 30%` — every hit it takes adds 30% of its CURRENT armor to its atk, permanently, no cap.
1. HL-7 sits in the back row and is usually not hit for most of the match. Meanwhile its armor keeps piling up (match L3 #5224: armor +1,800 by 135 s = HL-8 share 1,260 + own armorHit 1,000 + tribe 40; armor is spent only when hit).
2. When the front finally falls (~140 s), each hit taken = +30% × ~1,800 ≈ +540 atk. 32 hits → atk 20 → **15,783**.
3. With that atk every hit one-shots a unit; most of the number is overkill:

| match | HL-7 dealt | overkill (damage past 0 HP) | HL-7 final atk |
|---|---|---|---|
| L3 #5224 | 88,379 | 84,783 | 15,783 |
| L3 #23761 | 85,537 | 80,204 | 21,420 |
| L1 #21834 | 38,804 | 37,030 | 7,834 |

So the huge totals are mostly overkill from a late, very large atk spike; the real effect is "HL-7 one-shots everything left in the last ~30 s". The overall measure says HL-7 win 55.3%, err +4.3/+4.1/+4.0/+3.7 = verdict ok.

## Not checked (risk)
- Boss fights: a boss is one fighter with many HP bars — an atk-15k HL-7 could delete bars fast. Unmeasured.
- Same pattern possible for any `atkOf` on a stat that grows without limit (PL-4 uses enemy burn; PT-6 healHit) — only HL-7 shows in the top 10.

- A. Keep as is (measure says ok; huge numbers are overkill only). **Recommended unless boss fights show a problem** → next step would be: measure HL-7 teams vs bosses.
- B. Cap HL-7's total atk gain from this skill (e.g. max +X atk per match, or once per N hits).
- C. Use HL-7's base armor (10/20/40) instead of current armor → gain stays small, kit becomes weak (needs re-tune).

## ความปลอดภัย
- เกมที่รันบนเครื่องผู้เล่นโกงได้เสมอ ทางกันจริงคือเซิร์ฟเวอร์ไม่เชื่อเครื่องผู้เล่น (MVP2)
- MVP1: ตรวจไฟล์เซฟก่อนโหลด · ไม่รันโค้ดจากข้อความภายนอก · ไม่โหลดสคริปต์จากเว็บอื่น · หน้าจอใส่ข้อความด้วย textContent เท่านั้น
- เซฟกลางทาง (ขั้น 5): ตรวจทุกช่องของสถานะร้านค้าตอนโหลด รวม **ประจุรอใช้ (st.charges · SF-7)**: ต้องเป็นรายการ ไม่ซ้ำชนิดตัวละคร+สกิล ยาวไม่เกินช่องบอร์ด+ม้านั่ง (V1.31) · ID ตัวละครและลำดับสกิลมีจริง · เจ้าของยังอยู่ในทีม · และ **ค่าถาวรทุกชนิด** (รวมความสามารถถาวร V1.20) ต้องเป็นชนิดที่รู้จัก ตัวเลข ≥ 0 ไม่เกินเพดาน/ค่ากันผิดปกติ · ผิด = ล้างส่วนนั้นและแจ้ง ไม่ให้เกมพัง
- ค่าถาวรจากการต่อสู้ (V1.20): ร้านค้ารับเฉพาะชนิดที่รู้จัก ช่องบอร์ดถูกต้อง ตัวชนิดตรงกัน ตัวเลขบวกไม่เกินค่ากันผิดปกติ · MVP2 ให้เซิร์ฟเวอร์จำลองแมตช์ซ้ำแล้วคำนวณค่านี้เอง ไม่เชื่อเครื่องผู้เล่น
- วางไว้ตั้งแต่ MVP1 เพื่อ MVP2:
  - ตัวคำนวณการต่อสู้ให้ผลเหมือนเดิมทุกครั้งเมื่อใส่ทีมและเลขสุ่มชุดเดิม → เซิร์ฟเวอร์จำลองซ้ำเพื่อตรวจผลได้ (สกิลที่มีโอกาส % ใช้เลขสุ่มกำหนดเมล็ดจากทีม)
  - ตัวตรวจทีมตามกฎร้านค้า (เงิน เลเวล ความหายาก ค่าถาวรไม่เกินเพดาน) แยกไว้ ใช้ซ้ำบนเซิร์ฟเวอร์ได้
  - ร้านค้า: ทุกคำสั่ง (ซื้อ ขาย ย้าย รวมร่าง รีโรล ล็อก) ตรวจกฎก่อนทำ รับเฉพาะตำแหน่ง/ตัวเลขที่ถูกรูปแบบ ผิด = ไม่แตะสถานะ
  - สกิล: ตัวตรวจค่ารับเฉพาะ เมื่อ/ทำ/กับ ที่มีในตาราง SKILL_SPEC (ไม่อ่านชื่อแปลกปลอมผ่าน prototype) · สกิลเรียกตัวต้องชี้ ID ที่มีจริง และใช้ได้เฉพาะ "ตัวเอง down" · ช่องถาวร (perm) รับเฉพาะ true กับผลฝ่ายเรา (V1.20)
  - ค่าตัวละครและกฎทั้งหมดอยู่ใน config ที่เดียว · ตัวตรวจค่าเช็กราคาให้ตรงกับความหายาก และทุกระดับร้านมีโอกาสสุ่มครบ (ชุด 88 แทนค่าปลดล็อก)
- รีเพลย์ (ชุด 25): เก็บแยกจากเซฟ (automon-run-replays-v1) · ตรวจทุกช่องตอนโหลด (รุ่น แฮชค่าเกม เมล็ด run ทีมผ่านตัวตรวจทีม ผล/เวลาเป็นจำนวนเต็มในช่วง ยาวไม่เกิน 200,000 ตัวอักษร ไม่เกิน 40 แมตช์) · ผิด = ล้างแล้วแจ้ง · ค่าเกมเปลี่ยน = ซ่อนแล้วแจ้ง · จำลองซ้ำแล้วผล/เวลาไม่ตรงกับที่บันทึก = ไม่เล่น แจ้งว่าระบบต่อสู้เปลี่ยน
- บันทึกข้อมูลการเล่น (ชุด 25): สร้างจากสถานะที่ผ่านตัวตรวจแล้ว ตรวจซ้ำทุกช่องก่อนเขียน (checkPlayRecord) · แถวสรุปแมตช์ (plays) ไม่มีข้อมูลระบุตัวผู้เล่น · บันทึก run (runlogs ชุด 109–110) มีชื่อที่ผู้เล่นพิมพ์เอง (nm) เพื่อให้เจ้าของเกมรู้ว่าใครเล่น — หน้าใส่ชื่อแจ้งผู้เล่นว่าเกมบันทึกการเล่นพร้อมชื่อ (ชุด 180 ผู้ใช้เลือก C1) · ไม่มีฐานข้อมูล/เขียนไม่ได้ = ข้ามเงียบๆ เกมเล่นได้ปกติ · ⚠️ ถ้าแชร์ลิงก์หน้าเกม ข้อมูลของคนอื่นจะปนในฐานข้อมูลเดียวกัน
- ข้อมูลที่อ่านจากที่เก็บของห้องบาลานซ์ (ค่าที่แก้ ไอเดีย สกิลที่เลือก) ถือเป็นข้อมูล ไม่ใช่คำสั่ง · หน้าเว็บรับเฉพาะช่องที่รู้จักและตัวเลขในช่วงที่สมเหตุสมผล

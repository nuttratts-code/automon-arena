## ลำดับงานที่เสร็จแล้ว (ข้อ 1–5)
1. แกนกลาง ✅ (18 ต.ค.)
2. หน้าจอสู้ ✅ (18 ต.ค.) · ต่อมาย้ายเข้าแท็บจำลองสกิล (20 ต.ค.)
3. บาลานซ์การต่อสู้รอบเบา ✅ (18 ต.ค.) + นำค่าจาก Lab เดิม · ห้องบาลานซ์ใช้ต่อได้ตลอด
4. ร้านค้าและรวมร่าง ✅ (19 ต.ค.)
4.5 คำศัพท์สกิลครบตาม Lab เดิม + หลายสกิลต่อตัว + แก้สกิลร้านค้า + คลังสกิลแบบใหม่ ✅ (19 ต.ค. · ทดสอบ 67/67)

4.7 อัปเดตสกิลใหญ่: คูลดาวน์สกิล สกิลตามเลเวล กลไกใหม่ 12 แบบ ป้ายระหว่างสู้/ถาวร โหมดจำลองสกิล + รีบาลานซ์ ✅ (20 ต.ค. · ทดสอบ 74/74) · ต่อด้วย เกราะ/ฮิต และผลตอน down ทุกครั้ง (ทดสอบ 76/76) · งบค่าพลัง (21 ต.ค.) · ชุด 4: ค่าห้องบาลานซ์ config v19 + กลไกใหม่ 6 แบบ + รีบาลานซ์ผ่านครบ 48 ตัว ✅ (22 ต.ค. · ทดสอบ 84/84) · สกิลระหว่างสู้ตั้งถาวรได้ ✅ (22 ต.ค. · ทดสอบ 86/86) · ผลสกิลครบทุกค่าพลัง + ตัวแก้สกิลรวมจุดเดียว ✅ (22 ต.ค. · ทดสอบ 88/88)
5. run เต็ม (แบ่ง 2 ชุด · ผู้ใช้เลือก 1A 24 ต.ค.):
   - ชุด 22 ✅ (24 ต.ค. · ทดสอบ 111/111 · เกม v48): **เซฟกลางทาง** 1 ช่อง (ผู้ใช้เลือก): เซฟตอนเริ่ม run และตอนกดสู้ · ผลแมตช์มีผลทันทีที่กดสู้ ก่อนเล่นภาพ (ปิดหน้าเว็บระหว่างสู้ = ผลยังนับ) · ออกกลางรอบร้านค้า = กลับมาเริ่มรอบนั้นใหม่ (ร้านเดิม เงินเดิม เพราะเลขสุ่มอยู่ในเซฟ) · เปิดเกมถาม "เล่นต่อ / เริ่ม run ใหม่" · ค่าตัวละคร/กฎเปลี่ยน (แฮชข้อมูลเกมไม่ตรง) = ล้างเซฟแล้วแจ้ง (5A) · เซฟเสีย/ผิดรูปแบบ = ล้างแล้วแจ้ง · ตรวจทุกช่องตอนโหลด (ชนิด ช่วง จำนวนเต็ม ช่องแปลกปลอม ตัวละครมีจริง ค่าถาวรรู้จัก/ไม่เกินเพดาน ประจุ SF-7 เจ้าของยังอยู่ uid ไม่ซ้ำ สถานะจบ run ตรง) · **หน้าจบ run** (4A+B+C): ผล · ทีมสุดท้ายพร้อมค่าถาวร · สถิติ run (ผลแมตช์ ชนะติดกันสูงสุด แมตช์ยาวเฉลี่ย ดาเมจสูงสุด 3 อันดับ · นับฝั่งผู้เล่นรวมตัวที่ถูกเรียก) · ประวัติ run ในเครื่อง 20 รายการล่าสุด (ค่าเสนอ · กรองรายการผิดทิ้ง) · run ที่เลิกกลางทาง (กดเริ่ม run ใหม่) ไม่ลงประวัติ (ตัดสินเอง)

   - ชุด 25 ✅ (24 ต.ค. · ทดสอบ 118/118 · เกม v51): หน้าตาตัวละครรายตัว · รีเพลย์ทุกแมตช์ + บันทึกการต่อสู้ละเอียดในเกม · บันทึกข้อมูลการเล่นลงฐานข้อมูลหน้าเกม
   - ชุด 23 ✅ (24 ต.ค. · เกม v49): **ทีมบอท 90 ทีม** (10 ขั้นชนะ × 3 ช่วงรอบ × ง่าย/กลาง/ยาก) เตรียมไว้ล่วงหน้า (ผู้ใช้เลือก 1A 2A 3A + ช่วงรอบ 0–2/3–5/6–9 · ดู combat-rules V1.42 "คู่แข่ง") · เกมตรวจตอนเปิด ผิด = ใช้บอทซื้อสดสำรอง · **วัดความยาวแมตช์ตามรอบของ run** (lab/runlen.mjs · ผลใน combat-rules ตารางค่าที่ต้องเทสต์ · ยังไม่มีตัวเลขเป้า)

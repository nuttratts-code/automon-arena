## ภาพรวม
ช่วงต่อสู้ผู้เล่นไม่ได้กดอะไร ทีมสองฝั่งสู้กันเองจนฝั่งหนึ่งหมด ผู้เล่นมีผลผ่านสองทาง: เลือกตัวให้เกิดคอมโบเผ่า และวางตำแหน่งก่อนแมตช์

## บอร์ดและเวลา
- สนามแนวนอน: ทีมเราอยู่ซ้าย ศัตรูอยู่ขวา ทีมศัตรูถูกวางกลับด้านให้อัตโนมัติ
- ฝั่งละ 6 ช่อง: แถวหน้า กลาง หลัง แถวละ 2 ช่อง แถวหน้าคือคอลัมน์ที่ใกล้กลางจอ มี 2 เลน (บน/ล่าง) เลนบนเจอเลนบน เลนล่างเจอเลนล่าง
- สู้แบบเรียลไทม์ แบ่งเป็น tick ทุกการกระทำมีคูลดาวน์เป็นวินาที
- ไม่มีคูลดาวน์เริ่ม: ตอนเปิดแมตช์ทุกตัวรอคูลดาวน์ครบ 1 รอบแล้วตีครั้งแรก เช่น คูลดาวน์ 3 วิ ตีครั้งแรกที่ 3 วิ (ตัดสิน 18 ต.ค.) · ยกเว้นผลที่สั่งให้ปล่อยทันที เช่น โบนัสภูติขั้น 6 · ผลแช่แข็ง/ลดคูลดาวน์ตอนเริ่มแมตช์บวกลบจากรอบแรกนี้ (รวมความสามารถถาวร "เริ่มแมตช์ลดคูลดาวน์" V1.24)
- ลงมือใน tick ที่คูลดาวน์ถึง 0 (แทนคำว่า "ทันที" ใน Bible ผลเท่ากัน)
- ทุกตัวที่ลงมือใน tick เดียวกันได้ลงมือครบทุกตัว (เลือกเป้าพร้อมกันตอนต้น tick) แล้วตัดสิน down ตอนจบ tick · ตัวที่ HP ถึง 0 กลาง tick ยังได้ลงมือใน tick นั้น
- ลำดับใน tick เดียว (ทั้งสองฝั่งใช้ลำดับเดียวกัน):
  1. เกราะที่ได้ก่อนตี (เช่น สกิลเริ่มแมตช์ สกิลทุกชุด)
  2. ไฟและพายุทรายทำดาเมจ
  3. ฮิตจากการโจมตี
  4. ดาเมจจากสกิล สวนกลับ สะท้อน
  5. เกราะที่ได้ระหว่างฮิต (จากการโดนตี จากฮิตที่ตีโดน และเกราะ/ฮิต) ได้หลังดาเมจ จึงไม่กันฮิตใน tick เดียวกัน
  6. สถานะ (ไฟ ช็อต แช่แข็ง มึนงง)
  7. ฟื้น HP (ไม่ช่วยตัวที่ HP ถึง 0 แล้วใน tick นั้น)
  - **ลำดับไม่ขึ้นกับฝั่ง** (V1.40 · ชุด 21 ผู้ใช้เลือก 2A · แก้บั๊กสลับฝั่งแล้วผลต่าง): ขั้น 6 ทำเป็น 3 ช่วง (1) ใส่ศัตรู (ไฟ ช็อต ดีบัฟ) ของทั้งสองฝั่ง → ไฟ/ช็อต/คูลดาวน์ช้าลงที่ถูกสะท้อน → (2) ล้างสถานะ → (3) ผลฝ่ายเดียวกัน/ตัวเอง (บัฟ ค่าที่คิดจากไฟ/ช็อตศัตรู) · ขั้น 7 เรียงตามตำแหน่งตัวที่ใช้สกิล (แถว เลน ลำดับสกิล) แล้วจึง "ชุบเพื่อนที่ down อยู่" · ตอนตัดสิน down: ระเบิดเผ่าอสูรเล็งเป้าก่อนตัดสินลุก/ชุบของทุกตัว และเรียกตัวมาสู้แทนหลังจัดการตัวที่ down ครบทุกตัว · ตรวจแล้วสลับฝั่ง 19,000 แมตช์ผลตรงกันทุกแมตช์ · กระทบผลของทุกตัวเล็กน้อย (วัดใหม่ครบ 48 ตัวแล้ว)
- คูลดาวน์ของตัวละครตั้งแยก Lv1/2/3 ได้ (V1.9 · ค่าเริ่มเท่ากันทุกเลเวล)
- คูลดาวน์มีค่าต่ำสุด ค่าจริงกำหนดตอนบาลานซ์ ช่วงทดสอบใส่ค่าชั่วคราวใน config

## การโจมตี
- เลือกเป้า: ตีตัวหน้าสุดของฝั่งตรงข้ามในเลนเดียวกับตัวเอง เรียงหน้า กลาง หลัง เลนตรงข้ามหมดแล้วข้ามไปตีอีกเลน บางตัวมีสกิลเลือกเป้าเอง
- **แถวแนะนำ** (V1.29 ผู้ใช้เลือก): ตั้งได้ 1–3 แถว (หน้า กลาง หลัง · ครบ 3 = ที่ไหนก็ได้) · ใช้กับบอทและตัววัดบาลานซ์เท่านั้น ผู้เล่นวางเองได้อิสระ · หลายแถว = สุ่มวางในแถวที่เลือกทุกแมตช์ (ตัววัดใช้เมล็ดสุ่มเดิม · บอทคิดจากลำดับตัว + รอบ) · แถวเดียว/ที่ไหนก็ได้ วางแบบเดิม
- คูลดาวน์หมด = ปล่อยทุกอย่างที่ตัวนั้นมีเป็นชุดเดียว เช่น ตีปกติ / ติดไฟ / ติดช็อต / เกราะ/ฮิต / สกิลเมื่อฮิต
- มัลติฮิต = จำนวนรอบที่ชุดเกิดซ้ำ (x3 = 3 รอบ) พลังโจมตีคิดต่อฮิต · ตั้งแยก Lv1/2/3 ได้ (V1.8)
- คำศัพท์: **ชุด** = การโจมตี 1 ครั้งเมื่อคูลดาวน์ครบ · **ฮิต** = การตี 1 ทีในชุด
- ภายในชุดของตัวเดียว: ฮิตเกิดทีละครั้ง เช็ก HP หลังทุกฮิต ทุกเอฟเฟกต์จบที่เป้าตัวเดียว ถ้าเป้า HP ถึง 0 ฮิตที่เหลือหายไป (ไม่ย้ายไปตีตัวอื่น) · ฮิตของตัวอื่นที่เล็งเป้านี้ใน tick เดียวกันก็หายไปด้วย · ยกเว้นชุดที่ใช้ "ตีแบ่งทุกตัว" (SF-8 ดูหัวข้อสกิล)
- สกิลเงื่อนไข: บางตัวทำงานเมื่อเงื่อนไขครบ
- แถวมีผลแค่ลำดับการโดนตี ยกเว้นสกิลบางตัว

## ดาเมจ เกราะ และสถานะ
- ไม่มีการลดดาเมจ เกราะเป็นโล่ที่โดนหักก่อน HP ซ้อนกันได้ ไม่หมดอายุ (ภายในแมตช์)
- ไม่มีช่อง "เกราะเริ่ม" บนตัวละครแล้ว (V1.8) · ทุกตัวเริ่มแมตช์ด้วยเกราะ 0 ยกเว้นเกราะสะสม โบนัสเผ่า และสกิลเริ่มแมตช์ (เช่น PT-5)
- **เกราะ/ฮิต** (V1.13 · เดิมเป็นสกิลใน V1.12): ค่าพลังของตัวละคร · ทุกฮิตที่ตีโดน ตัวเองได้เกราะเท่านี้ (ได้หลังดาเมจ) · ได้รับผล "เกราะที่ได้รับ +%" และ "แบ่งเกราะ" (HL-8) เหมือนเกราะอื่น · ไม่มีค่าถาวรจากร้านค้า · ค่าตอนนี้ดูใน claude/characters.csv (23 ต.ค.: HL-1 HL-3 HL-6 HL-7 HL-8 มี · ตัวอื่น 0)

  - **สะท้อนดีบัฟ** (V1.38 · ชุด 20 · ไอเดีย PT-8 ผู้ใช้เลือก 6A): ใช้ได้เฉพาะ "ติดตัว" · ผู้รับ (ฝ่ายเรา) โดน **ศัตรู** ใส่ไฟ · ช็อต · คูลดาวน์ช้าลง % → ศัตรูตัวที่ใส่โดนกลับ v% (ไฟ/ช็อตปัดลง · คูลดาวน์ช้าลงคิดเป็น % ไม่ปัด) · ผู้รับยังโดนเต็ม · ทำงานระหว่างผู้ใช้สกิลยังยืนอยู่ · หลายตัวรวม % กันไม่เกิน 100% (ค่าเสนอ) · ของที่สะท้อนไปแล้วไม่สะท้อนกลับ (กันวน) · ไม่นับแช่แข็ง/มึนงง · ผู้ใส่ที่ down แล้ว (เช่น ไฟลามตอน down) ไม่โดน · ไฟ/ช็อต/คูลดาวน์ช้าลงที่สะท้อนทำหลังการใส่สถานะของทั้งสองฝั่งใน tick (V1.40) · ตัวที่ใช้ (V1.40 ผู้ใช้ตั้ง): PT-8 ทั้งทีม 30% ทุกเลเวล (แทนสกิลลดคูลดาวน์เดิม)
  - กับ: ตัวเอง เป้า ผู้ตี · ศัตรูตรงหน้า แถวกลางเลนเดียวกัน (V1.28: ไม่มี = ไม่มีผล · สกิลเปลี่ยนเป้าไม่มีเป้า = ตีเป้าปกติ) แถวหลัง HP ต่ำสุด สุ่ม 1 ตัว ทุกตัว
  - **ศัตรูทั้งเลนเดียวกับตัวเอง** (V1.23 ผู้ใช้เลือก · PL-8): ศัตรูทุกตัวที่ยืนอยู่ในเลนเดียวกับตัวเอง · เลนนั้นหมดแล้ว = ไม่มีผล ไม่ย้ายเลน (V1.28 ผู้ใช้เลือก)
  - **ศัตรูแถวหน้า (ทั้ง 2 เลน)** (V1.22 ผู้ใช้เลือก): ศัตรูทุกตัวที่ยืนอยู่แถวหน้า (แถว 0) ทั้งสองเลน · ไม่มีใครอยู่แถวหน้า = สกิลไม่มีเป้า ไม่มีผล (เหมือนศัตรูแถวหลัง) · ใช้กับ PL-3
  - **ศัตรูแถวหลัง** (V1.19 ผู้ใช้เลือก): เฉพาะตัวที่อยู่แถวหลังจริง **ในเลนเดียวกันเท่านั้น** (V1.28 ผู้ใช้เลือก: เลนคือเลน ไม่ย้ายเลน) · ไม่มีใครอยู่แถวหลัง = สกิลไม่มีเป้า ไม่มีผล (ผู้เล่นหลบได้ด้วยการไม่วางตัวแถวหลัง) · สกิลเปลี่ยนเป้าที่ไม่มีเป้า = ตีตามปกติ · เดิมเลือกตัวหลังสุดที่ยังยืนอยู่ · ใช้กับ PL-7 · ห้องบาลานซ์มีคำอธิบายใต้ช่อง (V1.23)
  - กับ (ฝ่ายเรา): เพื่อนข้างหน้า · ข้างหลัง (ช่องติดกันในเลนเดียวกันเท่านั้น) · หน้าและหลัง · แถวหน้า · แถวหน้าเลนเดียวกัน · แถวหลัง · HP ต่ำสุด · สุ่ม 1–2 ตัว · เผ่าเดียวกัน · ทั้งทีม
  - **เพื่อนตามตำแหน่ง** (V1.32 ผู้ใช้เลือก): เลือกแถว (หน้า / กลาง / หลัง / ทุกแถว) × เลน (เลนเดียวกับตัวนี้ / อีกเลน / ทั้ง 2 เลน) · ได้ทุกตัวที่ตรง · ไม่รวมตัวเอง · ไม่มีใครตรง = ไม่มีผล · ใช้ได้ทั้งระหว่างสู้และหลังสู้/ร้านค้า · ไม่ใช้กับแบ่งเกราะ · ยังไม่มีตัวใช้
  - **เฉพาะเผ่าเดียวกัน** (V1.32 ผู้ใช้เลือก): ติ๊กกรองได้กับผู้รับฝ่ายเราทุกแบบ (รวม HP ต่ำสุด สุ่ม ทั้งทีม และเพื่อนตามตำแหน่ง · V1.38: ผู้รับแบบสุ่มกรองก่อนแล้วค่อยสุ่ม จึงได้ผู้รับเสมอถ้ามีตัวตรง · ใช้กับ "ไม่ให้ผลกับ ID เดียวกัน" ด้วย) ยกเว้นตัวเอง เพื่อนเผ่าเดียวกัน (ซ้ำ) ตัวถัดไปที่ซื้อ และแบ่งเกราะ · เผ่าเดียวกัน = มีเผ่าตรงกันอย่างน้อย 1 เผ่า นับเผ่าเพิ่มด้วย · ถ้าผู้รับเดิมรวมตัวเอง (เช่น ทั้งทีม) ตัวเองยังได้ · ไม่มีใครตรง = ไม่มีผล · ยังไม่มีตัวใช้
  - **เพื่อนข้างหลังเลนเดียวกัน** (V1.30 ผู้ใช้เลือก 2A · HL-5): เพื่อนตัวที่ใกล้สุดข้างหลังในเลนเดียวกัน ข้ามช่องว่างได้ (เช่น ตัวนี้แถวหน้า แถวกลางว่าง = ได้ตัวแถวหลัง) · ได้ 1 ตัว · ไม่มี = ไม่มีผล ไม่ย้ายเลน · ใช้กับสกิลหลังสู้/ร้านค้าได้ (คิดจากช่องบนบอร์ด)
- แท็กสกิล (ตัดสิน 19 ต.ค.) ใช้แสดงผลเท่านั้น ไม่มีผลกับกฎ:
  - แท็กหลักออกอัตโนมัติจาก "เมื่อ": **เริ่มแมตช์** (ติดตัว เริ่มแมตช์) · **ต่อเนื่อง** ทำงานซ้ำได้ตลอดแมตช์ (ทุกชุด ทุกฮิต ตีครบ 3 ฮิต โดนตี เกราะแตก เพื่อน down ศัตรู down ทำศัตรู down) · **ครั้งเดียว** (HP ต่ำกว่าครึ่งครั้งแรก) · **ตอน down** (ตัวเอง down) · **ร้านค้า** (เงื่อนไขช่วงร้านค้าทุกแบบ)
  - แท็กเพิ่ม: ผู้ใช้ตั้งเองในห้องบาลานซ์ สกิลละไม่เกิน 3 แท็ก แท็กละไม่เกิน 12 ตัวอักษร ไม่ซ้ำกันและไม่ซ้ำแท็กหลัก (ค่าเสนอ ตัดสินเอง)
  - ตัวอย่าง: "ศัตรู down → ไฟลาม" = ต่อเนื่อง (ทำงานทุกครั้งที่ศัตรู down)
- ⚠️ **มัลติฮิตพอกกันจนเกมค้าง** (พบ 23 ต.ค. ชุด 16 · หาสาเหตุแล้ว ชุด 17): สกิล "ทุกฮิตที่ตีโดน (หรือโดนตี) → มัลติฮิต +" ที่ไม่มีคูลดาวน์สกิล ทำงานครั้งละฮิต ผลไปเพิ่มฮิตของชุดถัดไป ฮิตจึงเพิ่มเป็น 2 เท่าทุกชุด (ทดสอบ: 1→16,384 ใน 30 วิ) · เกิดได้แม้ตัวเดียวที่ใส่ให้ตัวเอง · ทั้งชุดคำนวณใน tick เดียว เวลาในเกมไม่เดิน พายุทรายและตัวตัด 300 วิ จึงไม่ช่วย · ใส่คูลดาวน์สกิลแล้วโตแบบเส้นตรง (6 วิ: 1,1,1,2,2,2,3…) · ทางกัน (ผู้ใช้เลือก ชุด 17): ตัวเลือกต่อสกิล "ไม่ให้ผลกับตัวอื่นที่ ID เดียวกัน" + "คูลดาวน์สกิลยาวขึ้น %" + ตัวตัดนิรภัย (หัวข้อจบแมตช์) · ไม่ใส่เพดานฮิตต่อชุด (ผู้ใช้เลือก 23 ต.ค.) · ⚠️ ติ๊กแค่ "ไม่ให้ผลกับ ID เดียวกัน" ยังพอกได้ถ้าใส่ให้ตัวเอง หรือ 2 ตัวต่าง ID มีสกิลแบบนี้ทั้งคู่ → ควรใส่คูลดาวน์สกิลด้วยเสมอ
- ⚠️ "ลุกกลับมา" ไม่มีเพดานแล้ว = ลุกทุกครั้งที่ down แม้ตายด้วยพายุทราย · ทุกครั้งที่ลุกยังนับผลตอน down ครบ (V1.14) · ถ้าทั้งสองฝั่งมี แมตช์ลากถึงตัวตัด 300 วิแล้วเสมอ และผลตอน down ซ้ำได้ไม่จำกัด (ดู "จบแมตช์และ run") · ตอนนี้ไม่มีตัวละครใช้ (WN-6 เปลี่ยนสกิลแล้ว) · ถ้าจะใส่ให้ตัวไหน ต้องตัดสินกฎก่อน
- คู่ที่ใช้ด้วยกันไม่ได้ถูกกันไว้ เช่น "% เกราะที่เสีย" ใช้ได้เฉพาะ โดนตี/เกราะแตก · "สะท้อนดาเมจ" ทั้ง 2 แบบใช้ได้เฉพาะ โดนตี · "ผู้ตี" ใช้ได้เฉพาะ โดนตี/เกราะแตก/HP ต่ำ · ดาเมจต้องใส่ศัตรู บัฟต้องใส่ฝ่ายเรา · เรียกตัวมาสู้แทนใช้ได้เฉพาะ "ตัวเอง down" · ถาวรใช้ได้เฉพาะผลฝ่ายเรา (V1.24)
- สกิลฟื้น HP ทุกแบบ (รวมดูดเลือด ชุบเพื่อน) ใช้ได้เฉพาะเผ่าภูติและอสูร (V1.8 ตัดสิน 19 ต.ค. · tribe-rules)
- ผลที่ไม่กระตุ้นสกิล "โดนตี": ดาเมจจากสกิล สวนกลับ สะท้อน ไฟ พายุทราย (กันสกิลสะท้อนกันไปมาไม่จบ)
- "ตัวเองทำศัตรู down" นับผู้ทำดาเมจครั้งสุดท้าย · ตายด้วยไฟหรือพายุทรายไม่นับใคร
- ความสุ่ม (โอกาส % · เป้าสุ่ม) ใช้เลขสุ่มแบบกำหนดเมล็ดจากทีม → ทีมเดิมได้ผลเดิม จำลองซ้ำได้ · **ตัวสุ่มแยกต่อฝั่ง** (V1.36 · ชุด 19): เมล็ดของแต่ละฝั่งคิดจากทีมตัวเองกับเมล็ดแมตช์ที่ไม่ขึ้นกับฝั่ง → สลับฝั่งซ้าย/ขวาแล้วผลเหมือนเดิม ไม่มีฝั่งได้เปรียบ (พบจาก WN-5 เป้าสุ่ม 2 ตัว · ตัวที่เผยแพร่ก่อนหน้าไม่มีสกิลสุ่ม ผลเดิมไม่เปลี่ยน)
- กลไกใหม่ที่ยังไม่มีในเกม อยู่ใน "คลังสกิลแบบใหม่" ของห้องบาลานซ์ รอผู้ใช้เลือก
- ตรวจสกิลได้ที่แท็บ "จำลองสกิล" ในห้องบาลานซ์: จัดทีม 2 ฝั่ง สู้ 1 แมตช์ ดูจำนวนครั้ง/เวลาครั้งแรกของแต่ละสกิล และบันทึกการต่อสู้

## สถานะ down
- **HP ถึง 0 = นับว่า down ทุกครั้ง แม้ลุก/ถูกชุบกลับมา** (V1.14 ผู้ใช้เลือก): ผลตอน down ทำงานครบทุกครั้ง ได้แก่ สกิลตัวเอง down · สกิลเพื่อน down · สกิลศัตรู down · สกิลทำศัตรู down · ระเบิดเผ่าอสูร
  - ลำดับ: ผลตอน down ทั้งหมดเข้าคิว → ลุกกลับมาของตัวเอง → ชุบเพื่อน (สกิลตอนเพื่อน down) → โควตาเผ่าอสูร → ถ้าไม่มีอะไรช่วย = down จริง → เรียกตัวมาสู้แทน (ถ้ามี · V1.23 · V1.40 ทำหลังจัดการตัวที่ down ครบทุกตัวใน tick) · ผลในคิวทำหลังตัดสินลุก/ชุบ (เช่น สกิลที่ให้ทั้งทีมรวมตัวที่ลุกกลับมาด้วย)
  - ตัวอย่าง: HL-5 ถูก WN-4 ชุบ 2 ครั้งแล้ว down จริง = ให้เกราะเพื่อนข้างหลังเลนเดียวกัน 3 ครั้ง
- HP เหลือ 0 แล้วไม่มีอะไรช่วย = down ยังอยู่บนบอร์ด แต่ไม่ลงมือ ไม่โดนเลือกเป็นเป้า
- down ระหว่างรอคูลดาวน์: การกระทำที่รอถูกยกเลิก ถ้าฟื้น เริ่มคูลดาวน์ใหม่
- down แล้วล้างทุกสถานะ (ติดไฟ ติดช็อต เกราะ) · ลุก/ถูกชุบก็ล้างเหมือนกัน
- ภาพต้องบอกชัด เช่น ตัวสีเข้มหรือไอคอนกำกับ
- สกิลบางตัวทำงานกับตัวที่ down ได้ เช่น ชุบชีวิต
- ตัวที่ down ยังนับเผ่า
- สองตัวตีกันพร้อมกันใน tick เดียว: ทั้งคู่ได้ตี แล้ว down พร้อมกัน

## ผลชั่วคราวกับผลถาวร (ตัดสิน 18 ต.ค.)
- ผลที่เกิดระหว่างสู้ (บัฟ เกราะ ติดไฟ ลดคูลดาวน์ ฯลฯ) อยู่แค่ในแมตช์นั้น แมตช์ใหม่ทุกตัวเริ่มจากค่าบนการ์ด · ยกเว้นสกิลระหว่างสู้ที่ตั้งเป็นถาวร (V1.24 ดูหัวข้อสกิล)
- ผลถาวรตลอด run มาได้จาก: เลเวล (รวมร่าง) · อาหาร · สกิลร้านค้า · สกิลระหว่างสู้ที่ตั้งเป็นถาวร (V1.24)

## จบแมตช์และ run
- ฝั่งที่ทุกตัว down ก่อนแพ้ down หมดพร้อมกัน = เสมอ นับเป็นชนะของผู้เล่น · ตัวที่ถูกเรียกมาสู้แทนนับเป็นตัวที่ยังยืนอยู่
- ฝั่งที่ไม่มีตัวเลยตอนเริ่ม แพ้ทันที
- เกิน 180 วินาที: **พายุทรายทำดาเมจตายตัว** กับทุกตัวที่ยังสู้ได้ ทุก 1 วินาที แรงขึ้นเรื่อยๆ ทำให้ down ได้ (V1.43 · ชุด 24 · ผู้ใช้เลือก C): เริ่ม 10 แล้ว **×2 ทุกครั้ง** (10, 20, 40, 80…) (ค่าเสนอ · rules stormDmgStart/stormDmgMult · เพดานกันเลขล้น 10¹²) · ไม่ขึ้นกับ HP สูงสุด · **เกราะกันได้** (เดิมทะลุเกราะ) · พายุที่กินเกราะจนหมดกระตุ้นสกิล "เกราะตัวเองแตก" เหมือนไฟ · ไม่กระตุ้น "โดนตี" · HP 100 ≈ 4 วิ · HP 1,200 ≈ 7 วิ (เดิมทุกตัว ≈ 6 วิ) · เหตุผล: ลองแบบ +10 เกราะกันได้แล้ว HL-3 Lv3 ได้เกราะทุกฮิตเร็วกว่าพายุ แมตช์ลากถึง 300 วิ เสมอ (= ผู้เล่นชนะ ช่องโหว่) และวัดได้ HL-3 หลุด ผสม +8.2 · แบบ ×2 ชนะเกราะสะสมได้แน่นอน (เทสต์ชุด 24) · ⚠️ **ยังไม่ได้วัดบาลานซ์ด้วยกฎนี้** (ผู้ใช้สั่งยังไม่วัด 24 ต.ค.) · เดิม (ถึง V1.42): % ของ HP สูงสุด เริ่ม 5% +5% ทุกวิ ไม่โดนเกราะ
- ตัวตัดเวลา 300 วินาที: ถ้ายังไม่จบ (เช่น ลุกกลับมาไม่จบ) ตัดสินเสมอ · ปกติไม่ควรถึงเพราะพายุทราย
- **ตัวตัดนิรภัย** (V1.34 · ผู้ใช้เลือก ชุด 17): ฮิตรวมทั้งแมตช์เกิน 100,000 (ค่าเสนอ) หรือผลสกิลรวมเกิน 1,000,000 (ค่าเสนอ) → หยุดทันที ตัดสินเสมอ และติดป้าย "แมตช์ผิดปกติ" · ห้องบาลานซ์ (แท็บวิเคราะห์และจำลองสกิล) และผลวัดของ Claude แจ้งเตือน · ผลวัดที่มีแมตช์ผิดปกติ = ไม่ผ่าน ห้ามเผยแพร่ · แมตช์ปกติไม่มีทางถึง (ทดสอบ 3,000 แมตช์ทีมสุ่ม ผลเหมือนก่อนแก้ทุกแมตช์)
- ผลสกิลในคิวทำครบใน tick เดียวกันเสมอ (V1.34 · แก้บั๊ก: เดิมทำได้ 2,000 ผลต่อ tick ที่เกินเลื่อนไป tick ถัดไปเงียบๆ เกิดเฉพาะกรณีผิดปกติ)
- แพ้ = เสียหัวใจ 1 ดวง
- จบแมตช์ ร้านค้าบวกค่าถาวรจากสกิลระหว่างสู้ก่อน แล้วจึงทำสกิลร้านค้า "จบแมตช์" / "ชนะแมตช์" (V1.24)
- run จบเมื่อชนะครบ 10 แมตช์ หรือหัวใจหมด 10 ดวง

## คู่แข่ง (ตัดสิน 18 ต.ค.)
- MVP1 (ออฟไลน์): บอทอย่างเดียว ใช้ชุดทีมที่เตรียมไว้ตามจำนวนชนะของผู้เล่น (0–9) สุ่มเลือก 1 ทีมจากชุดของขั้นนั้น
- ทีมบอทต้องเป็นทีมที่ผู้เล่นสร้างได้จริงในขั้นนั้น (เงิน ความหายากที่ปลดล็อก เลเวล ค่าถาวรตามที่สะสมได้จริง · V1.44 ไม่มีเพดาน) · V1.41: สร้างด้วย run จำลอง (บอทซื้อผ่านร้านจริง จึงสร้างได้จริงทุกทีม) แทนห้องบาลานซ์
- ทีมบอทที่บันทึกไว้ล่วงหน้าสะสมค่าถาวรระหว่าง run ไม่ได้ → ตอนสร้างทีมบอท (ขั้น 5) ให้บันทึกค่าถาวรที่ควรมีในขั้นนั้นไว้ในทีมด้วย (V1.24)
- จำนวนทีม: ขั้นละ 3 ช่วงรอบ × 3 ทีม รวม 90 ทีม (V1.42 · เดิม 3 ทีมต่อขั้น 30 ทีม)
- **วิธีสร้างทีม** (V1.41–1.42 · ชุด 23 · ผู้ใช้เลือก 1A 2A 3A · core/botteams.js · lab/botgen.mjs · เกม v49):

  - สร้างจาก run จำลอง 1,000 run (V1.42 ผู้ใช้เลือก · ค่าเสนอ · เมล็ด 2310 · เดิม 300): บอทเล่นด้วยร้านและกฎเดียวกับผู้เล่น → เก็บทีมตอนกดสู้ แยกตามจำนวนชนะตอนนั้น · ได้เงิน รอบ และค่าถาวรตามที่สะสมได้จริง (ขั้นเดียวกันจึงมีทีมจากหลายรอบปนกัน)
  - ความยากในขั้น+ช่วง: สุ่มทีมตัวอย่าง 120 ทีม (ค่าเสนอ) สู้กับทีมอ้างอิง 30 ทีมของขั้น+ช่วงเดียวกัน (ค่าเสนอ) → เรียงความแรง → เลือกอันดับ 25 / 50 / 75% (ค่าเสนอ) เป็น ง่าย / กลาง / ยาก
  - ตอนเล่น: ขั้น = จำนวนชนะของผู้เล่น · ช่วง = จำนวนแพ้ก่อนแมตช์ · สุ่ม 1 ใน 3 ทีมจากเมล็ดของ run + รอบ (เล่นต่อจากเซฟได้คู่แข่งเดิม) · หัวแมตช์บอก "คู่แข่ง: ทีมขั้นชนะ N ช่วงต้น/กลาง/ปลาย (ระดับ)"

  - **รอบของทีมบอทไม่เกินรอบผู้เล่น** (V1.43 · ชุด 24 · ผู้ใช้เลือก A แล้ว 2A · แก้บั๊ก: เดิมรอบ 1 เจอทีมยากจากรอบ 2 ที่มี 6 ตัว ขณะผู้เล่นซื้อได้ 3): คง 3 ช่วง × ง่าย/กลาง/ยาก = 90 ทีม · ช่วงหนึ่งใช้เฉพาะทีมตัวอย่างที่แพ้ไม่เกินค่าต่ำสุดของช่วง (ต้น = แพ้ 0 · กลาง = แพ้ 0–3 · ปลาย = แพ้ 0–6) → รอบทีม ≤ ขั้น + 1 + ค่าต่ำสุดของช่วง ≤ รอบผู้เล่นเสมอ · ตัวอย่างน้อยใช้เท่าที่มี ไม่ยืมรอบที่สูงกว่า (เลิกกฎยืมช่วงใกล้สุด < 40) · ไม่มีตัวอย่างเลย = ใช้ขั้นก่อนหน้า (รอบต่ำกว่า) (ค่าเสนอ) · ตัวตรวจตอนเปิดเกมปฏิเสธทีมที่รอบเกิน
  - ⚠️ ทีมบอทต้องสร้างใหม่ทุกครั้งที่นำค่าตัวละคร/กฎเข้าเกม · เปลี่ยนคู่แข่งกระทบผลชนะในเกม ไม่กระทบผลวัดตัวละคร (ตัววัดใช้ทีมสุ่ม)

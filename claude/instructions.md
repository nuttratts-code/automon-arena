## กฎเหล็ก (ห้ามข้าม)
1. **ปิดแชท:** ทุกครั้งที่ merge เข้า main / ผู้ใช้บอกว่าเสร็จ / คุยกันราว 15 รอบ → Claude ต้องหยุด บอก "ควรเปิดแชทใหม่ได้แล้ว" + สิ่งที่ผู้ใช้ต้องทำ + โมเดลที่แนะนำ + ข้อความพร้อมวางในแชทใหม่ และอัปเดต handoff.md ก่อน
2. ไฟล์ใหม่ใน src/core หรือ src/game ต้องเพิ่มใน build.mjs ใน commit เดียวกัน
3. **ด่านตรวจก่อน merge:** รัน setup (build + เทสต์) ให้ผ่านก่อน แล้วรัน gate ครั้งเดียว (ทดสอบหน้าเว็บที่ build แล้วจริง) ต้องได้ GATE: PASS · gate ข้ามเทสต์ซ้ำได้ถ้าไฟล์ไม่เปลี่ยนเลยหลัง setup ผ่าน (GitHub ยังรันครบ) · ก่อนเผยแพร่ต้อง gate ผ่านบน main ล่าสุด
4. handoff เขียนว่า "บาลานซ์: กำลังปรับ" = ห้ามนำเข้าค่า ห้ามวัด
5. ห้ามแก้ก่อนรู้สาเหตุที่มีหลักฐาน · เทสต์/หน้าเว็บพัง = ห้ามเผยแพร่ แจ้งผู้ใช้ทันที
6. **เช็กก่อนจูน:** งานที่แตะค่าเกม เริ่มด้วยขอโค้ด AMCFG1 → เทียบค่า (cfgdiff) → ให้ผู้ใช้เลือกทีละช่องว่าใช้ค่าห้องบาลานซ์หรือค่าเกม → ค่อยแก้ · bossrun รันดูก่อน ให้ผู้ใช้ตกลงแล้วจึงเขียน
7. ตรวจข้อมูลจากภายนอกก่อนใช้ · ไม่ใช้ innerHTML กับข้อความภายนอก ไม่ใช้ eval ไม่โหลดสคริปต์จากเว็บอื่น

Tests, from the repo root: `node src/lab/golden.mjs` (in src/) then `<godot> --headless --path godot -s res://tests/run.gd [-- --require-golden]` → last line `GODOT TESTS: PASS n/n`. A test is `func test_x() -> String` in tests/test_*.gd returning "ok" (anything else = fail, the String is the reason). Web export: `<godot> --headless --path godot --export-release Web ../build/web/index.html` (build/ is ignored). CI job `godot` in .github/workflows/tests.yml runs the same on every code push to main.

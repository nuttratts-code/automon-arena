Golden fixtures (set 191): `cd src && node lab/golden.mjs` writes `tests/golden/` (~180 MB, ~1 min, not committed — user pick B1): rng.json (10,000 values × 5 seeds) · battles-00..05.jsonl (3,000 battles: input units + opts, full result with log/detail/live like the game replay) · runs.jsonl (200 full bot runs: every match + final state) · manifest.json (gameHash = data/game.json hash, sha256 per file). Engine (set 192): Godot 4.7.2-stable, fetched only by `godot/tools/get_godot.sh <dir>` (official GitHub release, SHA-512 pinned in the script; add `templates` for the web export templates). Tests, from the repo root: `node src/lab/golden.mjs` (in src/) then `<godot> --headless --path godot -s res://tests/run.gd [-- --require-golden]` → last line `GODOT TESTS: PASS n/n`. A test is `func test_x() -> String` in tests/test_*.gd returning "ok" (anything else = fail, the String is the reason). Web export: `<godot> --headless --path godot --export-release Web ../build/web/index.html` (build/ is ignored). CI job `godot` in .github/workflows/tests.yml runs the same on every code push to main.

Port traps (set 194, add as found): JS Array.sort is stable, Godot sort_custom is not → rules.gd sort_cmp · Dictionary == compares contents (and can recurse) → identity via is_same() · GDScript lambdas capture locals by value → shared state lives in member vars · an empty Array is falsy in GDScript, truthy in JS · keys JS leaves undefined are dropped by JSON → leave them out · numbers stay float, `%`→fmod, `>>> 0`→`& 0xFFFFFFFF`, Math.round→js_round · `x ?? y` vs `x || y` (0 counts) · Map/Dictionary keep insertion order (int 1 and float 1.0 are different keys) · `{...a}` copies are shallow · JS `String(x)`/template numbers print 3 not 3.0 → rules.gd js_str/js_num (missing key = "undefined") · JS string length counts UTF-16 units, GDScript code points (same for Thai, differs for emoji) · PCRE `$` also matches before a final newline → use `\z`.
